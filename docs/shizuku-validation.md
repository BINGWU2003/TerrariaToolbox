# Shizuku 验证版使用说明

版本 1.1 / 2，包名不变，使用原 Debug 签名。可覆盖安装第一阶段 APK；不要先卸载或清除数据，否则内部备份会丢失。

## 准备与连接

1. 从 [官方下载页](https://shizuku.rikka.app/download/)安装 Shizuku，按 [官方启动说明](https://shizuku.rikka.app/zh-hans/guide/setup/)通过开发者选项中的无线调试配对并启动。Android 14 可在手机上完成，不需要 Root 或连接电脑；仍依赖 ADB shell 调试服务。
2. 使用主用户，Shizuku 为无线调试 shell 模式。本版要求 API 13+、UID 2000，不支持 Root 模式、工作资料或其他用户。
3. 游戏包名须为 `com.and.games505.TerrariaPaid`。运行游戏生成配置，再完全退出。写回验收需要游戏实际使用的英文原配置；已为中文只能证明读取。
4. 点击“连接 Shizuku 并读取配置”，允许工具箱访问。检查实际路径、服务 UID、语言，点击“确认这是游戏原配置”。连接成功、可尝试写入、写回通过和游戏中文生效分别判断。

固定目标：`/storage/emulated/0/Android/data/com.and.games505.TerrariaPaid/config.json`。

## 备份、切换与恢复

英文配置点击“验证并切换中文”，确认游戏完全退出。应用重新读取，保存并回读核验原始备份，生成候选，持久化未完成记录，重新检查源哈希，再截断写入、同步、关闭和回读核验。只有完整回读通过才显示保存成功，之后需启动游戏确认中文。整数 `7` 不重复写入。

读取／写权限探测不会试写或创建配置。8 MiB 以上、符号链接、非普通文件、重复键、无效 JSON、不支持的语言字段均禁止修改。

- 设备重启后重新启动 Shizuku，再返回工具箱。应用恢复前台会重新检查服务、授权和文件，不自动重复写入。
- 授权拒绝后在 Shizuku 调整授权，再手动重试。连接超过 10 秒释放绑定，不无限重试。
- 显示“暂勿启动游戏”时，重新连接相同来源并“重新校验上次结果”；不一致时选择原始备份“完整恢复”。恢复前先备份当前字节，恢复后核对完整哈希。
- 恢复会还原按键、音量等全部配置。仅允许相同后端和来源恢复；旧 SAF 备份通过对应 SAF 来源恢复，或者导出后用已能访问目录的 MT 手动恢复。
- 无访问能力时仍可导出内部备份与报告。导出不是游戏文件替换；手动放回时最终名称为 `config.json`。

## 限制与验收

“其他授权方式”保留 SAF 入口。内部备份与操作记录位于 `noBackupFilesDir`，不上传、不随系统云备份迁移。本应用没有网络或管理所有文件权限。卸载／清除数据前先导出备份。

模拟器受控夹具只证明开发流程。手机上的游戏目录访问、中文生效和重启行为须按 [真机模板](shizuku-device-validation-template.md)验收；完整验收前不声明支持直接切换。本版尚未提供中文副本生成和导出流程，原真实样本保持不变。
