# 1.5 交互改版验证

日期：2026-10-11。版本：1.5 / versionCode 6。

## 依据与范围

已读取用户提供的[交互设计讨论](https://chatgpt.com/share/6acb37fa-3e9c-83ea-b5e5-1c0cdc7f201a)，并按 grilling 的三轮对齐结果实施：保留现有功能，交付 APK；底部首页／存档／工具；角色／世界顶部分类；先选文件后确认目标的引导式导入；记住目标并重新核实；移除日常设置备份、历史与恢复 UI，保留内部自动备份与异常恢复。

存档备份中心、覆盖／删除／重命名存档、游戏格式转换没有加入本版。未改动现有品牌素材、游戏目录访问白名单或 supplied 存档内容。

## 实现

- 统一顶部栏、底部导航与辅助页返回栈，设置与帮助不再附属于游戏语言。语言页明确仅支持国际服。
- 存档列表与导入向导拆开；支持文件名搜索、修改时间／名称／大小排序，默认最近修改。选择模式支持跨分类多选与当前搜索结果全选，导出操作和实际结果保持可见。
- 文件先在缓存中检查，不要求先连接 Shizuku。目标页连接并选择游戏版本／账号，确认清单后才允许写入。同名自动编号与独占创建、同步、SHA-256 回读保持原机制。
- 导入按文件报告进度与逐项结果；结果摘要与列表扫描提示分开，返回帮助不会清空当前文件或重放首页入口。
- SaveableStateHolder 保存页面分类、搜索和滚动／向导状态；目标记忆使用 noBackupFilesDir 原子文件，连接后核实账号存在。丢失授权禁用写入，取消／失败保留导出选择。
- 删除手动设置备份入口与对应主动备份方法；旧备份数据保留，仅未完成操作或损坏操作记录时展示异常恢复。损坏记录不允许盲目恢复写入，但可导出原字节用于排查。

## 验证边界

模拟器和隔离测试目录验证不等同于实体手机上的 Shizuku shell 文件访问或真实游戏加载。未在实体手机复测两种手机版游戏读取及本版语言切换。内部设置恢复机制继续保留原领域和文件访问检查；存档被强杀可能留下未确认的新文件，不承诺与语言事务同样的恢复保证。

页面往返和 Activity 重建保留当前 ViewModel 与可保存的 UI 状态；进程被终止后只持久化游戏版本／账号，需重新选择文件，存档最近操作记录也为当前会话记录。
