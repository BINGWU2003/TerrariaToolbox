# 第一阶段验证版操作说明

## 安装与准备

1. 在 Android 14 手机上安装 `TerrariaToolbox-validation-debug.apk`，允许当前安装入口安装 APK。
2. 确认目标游戏包名为 `com.and.games505.TerrariaPaid`。本阶段没有切换英文入口；实际写回验证需要游戏原配置的 `Language` 为整数 `1`。
3. **完全退出游戏**。不要让游戏与本应用同时修改配置。
4. 如已有 MT 导出的原配置，请另存一份；本应用仍会在每次写回前创建并校验内部备份。

真实样本 `docs/config.json` 已为中文（`Language = 7`），可用于读取验证，不能用于证明写回能力。开发测试仅在内存中生成英文副本，不会修改该样本。

## 目录或文件授权

点击“授权配置目录”，选择游戏配置所在目录；若目录入口无法使用，可尝试“选择配置文件”。不要连续反复申请系统不允许的目录。

目标位置：

```text
/storage/emulated/0/Android/data/com.and.games505.TerrariaPaid/config.json
```

核对页面显示的实际 URI、提供方、入口、读写状态和语言。取消选择只显示“已取消”。授权无法持久保存时会提示重启后可能需要重新授权。

当前只接受系统外部存储提供方能证明位置的目标文档为游戏原文件。路径匹配后点击“确认这是游戏原配置”，再次核对来源。来源无法确认、同名副本或只读授权均不会开放写回；仍可“保存原始备份”并导出。

## 验证并切换中文

仅当来源已确认、提供方标记可写且当前配置为英文时，可点击“验证并切换中文”。确认游戏已完全退出后，应用依次：

1. 重新读取并验证配置。
2. 保存原始字节备份，回读核对大小和 SHA-256。
3. 生成候选配置，只把根对象 `Language` 从整数 `1` 改为整数 `7`。
4. 保存未完成操作记录，重新检查源内容未变化。
5. 覆盖写入同一 URI，关闭并回读，检查完整内容和其他字段。

看到“配置已保存并回读校验”后，才启动游戏检查中文显示。退出并再次启动游戏，确认中文仍然保留。应用不会自动监控或关闭游戏，也不会自行认定游戏显示已生效。

配置已为 `7` 时不会自动重复备份或写入。未知语言编号、重复键、语言字段缺失、字符串、小数及非法 JSON 都禁止修改。

## 失败、中断与恢复

出现“暂勿启动游戏”或“需要检查或恢复”时：

- 保留所有原始备份，先重新授权同一原目标。
- 若上次写入可能已经完成，点击“重新校验上次结果”；内容必须与记录的完整候选哈希一致。
- 否则选择提示的备份标识，点击“完整恢复”，核对备份时间和来源，确认游戏退出后恢复。
- 恢复前会先备份当前内容，即使当前文件已损坏也尽量逐字节保留；读取或备份失败则中止恢复。
- 无法重新取得读写授权时，导出原始备份，再用已验证能访问目标目录的 MT 手动恢复。

完整恢复会同时还原音量、按键等其他设置。备份来源不同只能导出，不能一键恢复。未完成操作记录损坏时禁止继续写入，应先导出备份检查。

## 原始备份与验证记录导出

“导出原始备份”使用系统保存入口，默认名称为 `config-original-备份标识.json`。应用禁止覆盖源 URI及能识别的同一文档别名，导出后必须回读校验；无法回读时仅提示结果未确认。

页面显示实际保存名称和 URI。通过 MT 手动替换游戏配置时，最终文件名必须为 `config.json`；即使导出成功，也尚未替换游戏配置。卸载应用或清除数据会删除内部备份，请及时导出。

填写游戏发行版本和 MT 版本后，点击“导出验证记录”。报告包含设备、系统补丁、应用 targetSdk、提供方、授权入口和操作结果，不包含配置内容或配置中的用户标识。补充游戏中文显示、重启授权复用等人工结果，参照 `device-validation-template.md` 验收。

## 本阶段限制

本阶段没有生成中文副本并导出的备用编辑流程、完整工具箱首页或其他游戏工具。这些属于后续阶段。Android 14 真机完整验收前，不声明支持一键修改；目录受限时，应记录当前环境不支持直接写回。
