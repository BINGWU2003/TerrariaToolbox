# 1.4 使用说明

安装 `artifacts/v1.4/TerrariaToolbox-v1.4-debug.apk`，可直接覆盖安装旧版。首页按说明启动 Shizuku，再点击连接并允许授权。存档管理支持国服和国际服；游戏语言工具沿用国际服设置文件。

## 查看游戏存档

进入首页的「存档管理」，选择国服或国际服。国服只有一个账号时自动选择并显示账号 ID；多个账号时先选择要操作的账号。如果没有账号目录，先打开国服并登录，再完全退出游戏后刷新。国际服不需要选择账号。

「游戏里的存档」可以切换角色与世界列表，显示文件名、大小和修改时间。文件名不一定等于游戏里显示的名称。本版不解析装备、角色属性或世界进度。

## 导入存档

选择「内置存档」后勾选需要的文件，再点击导入；或者点击「从手机选择文件」，一次选择多个 .plr、.wld 或 ZIP。内置资源来自项目根目录的 `Masters Of Terraria`，包含 Galactus、Molt、Starduster、Vor 四个角色和一个物品世界。

确认窗口会显示目标游戏版本、国服账号以及文件清单。完全退出游戏后点击「已退出游戏，开始导入」。完成后查看逐项结果，成功的文件会出现在对应列表。

同名存档不会覆盖已有文件。工具箱在目标版本、账号和角色／世界目录内忽略大小写检查文件名，例如已有 `vor.PLR` 时导入 `Vor.plr`，会保存为 `Vor (1).plr`；这个名字也存在时继续使用 `Vor (2).plr`。同一批次中的重名文件也会依次编号。极长文件名会缩短末尾以容纳编号。存档内容原样保留，所以游戏里的角色或世界名称可能仍然相同。

## 导出存档

勾选角色或世界，点击「导出选中的存档」，选择下载等普通文件夹保存。可以跨角色、世界两个列表选择。

选择一个时导出原 .plr/.wld 文件；选择多个时导出 ZIP，内部分为 `Players/` 与 `Worlds/`，保留各自文件名。这种 ZIP 可通过「从手机选择文件」再次导入到任一支持的版本或国服账号。保存后会重新读取导出文件检查内容。

只导入导出 .plr/.wld 主文件，不包含 .bak 自动备份、地图探索和其他附属文件，也不会修改已有附属文件。工具箱复制原文件，不转换存档格式；是否能在游戏中读取取决于游戏版本。建议完全退出游戏后刷新和导出，避免游戏同时保存。

## 范围与限制

单个存档上限 64 MB，每批处理的实际内容上限 256 MB，一次最多选择 500 个存档。ZIP 中的存档应放在根目录或对应 Players/Worlds 目录；不安全路径、空文件和损坏的压缩内容会被拒绝。仅有附属文件的 ZIP 无法导入。

导入过程中保持游戏关闭。若授权中断或提示结果尚未确认，重新连接 Shizuku 并刷新列表后检查，不要把未确认的结果当作成功。

旧版语言切换、自动设置备份和恢复功能继续保留；恢复设置备份不会恢复角色或世界存档。
