# 1.6 使用说明

首页／存档／工具底部导航、搜索排序、账号记忆和语言异常恢复沿用 1.5。本版解决国际服与心动国服内置存档混用，存档仅可导入所属服。

## 内置存档

从首页或存档页进入「导入存档」，点击「浏览内置存档」。先选国际服／国服，再选角色／世界。浏览与选文件无需连接 Shizuku；默认当前记住的所属服。

| 所属服 | 角色 | 世界 |
| --- | --- | --- |
| 国际服 | Galactus、Molt、Starduster、Vor | 1_4_4+ALL_ITEMS MAP_-_By_Scopey(3)、（经典）言寺全物品1.4.5.8 |
| 国服 | 暂无内置角色 | （经典）心动国服 言寺全物品1.4.5.8 |

同服角色与世界可跨分类多选；切换所属服会清空内置选择。国服内置角色为空时可以选择手机中的国服角色文件。这个空状态只表示工具箱没有内置资源，已有国服游戏角色仍可正常列出与导出。

选好内置文件后，工具箱自动绑定同服目标。连接 Shizuku 并重新核实国服账号后，检查来源服、实际账号和清单，再完全退出游戏，点击「已退出游戏，开始导入」。另一服不可用于本次导入，需返回重新选文件。

## 手机存档与 ZIP

保持先选文件：支持多选 .plr／.wld 和 ZIP。基本检查包括非空、大小限制、ZIP 路径与解压上限。

- 已知世界标记 `relogic` 识别为国际服、`xindong` 识别为国服。只识别这两种标记，不进行完整游戏格式解析。
- 1.6 以后多文件导出 ZIP 带来源信息，检查清单、大小、SHA-256 和世界标记的一致性后读取所属服；ZIP 文件名不参与来源判断。
- 角色、无已知标记的世界及旧 ZIP 中的未知来源文件，需要明确选择「这是国际服存档」或「这是国服存档」。按原游戏或下载说明确认，不能通过声明覆盖已知来源。
- 同一批文件只能属于一个服。发现两服混合、来源与标记冲突或 ZIP 来源校验不一致时，整批停止，重新按服分批选择。其他不支持的文件仍逐项报告检查错误。

来源信息用于防止误选，不是签名认证。用户声明也不能证明文件可被具体游戏版本加载。同服仍需要目标游戏支持相应存档版本，文件名中的版本号只是资源名称；工具箱不转换、不解密或更改存档内容。

## 导出与现有行为

存档页选择版本与国服账号，在角色／世界中跨分类选择。单文件导出原 .plr／.wld，多个导出 ZIP；取消或失败保留选择。ZIP 的 `terraria-toolbox.json` 记录所属服与各主文件的路径、字节大小和 SHA-256，不记录账号 ID。删除、修改来源信息或替换文件后，重新导入可能被拒绝。

单角色文件重新导入仍需声明所属服；单世界文件按已知标记识别。旧 ZIP 仍支持，但未知来源需要声明。每次导入采用同名自动编号，保留已有文件；只复制主文件，不包含地图探索或 .bak。64 MB／文件、256 MB／批、500 个存档的限制保持不变。

安装 1.6 可覆盖同签名旧版。游戏目录访问仍通过 Shizuku，国服账号登录后需完全退出游戏再刷新。语言工具仅用于国际服，日常设置备份入口继续移除，内部自动备份和异常恢复保留。
