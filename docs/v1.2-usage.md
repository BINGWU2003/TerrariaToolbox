# 泰拉瑞亚工具箱 1.2 操作说明

版本 `1.2 / versionCode 3`，Android 14 或更新系统，Debug 签名，包名 `com.example.terrariatoolbox`。在手机上打开 `TerrariaToolbox-v1.2-debug.apk` 即可安装；已有 1.1 时选择更新，不要卸载或清除数据，否则内部备份和副本会丢失。

## 日常直接切换

1. 进入首页“中文切换”，默认“直接切换”。先运行游戏生成配置，再完全退出游戏。
2. 启动 Shizuku 并授权工具箱，点击“连接 Shizuku并读取配置”。官方说明：https://shizuku.rikka.app/zh-hans/guide/setup/ 。无线调试启动无需 Root 或电脑，仍依赖系统调试服务。
3. 核对目标 `/storage/emulated/0/Android/data/com.and.games505.TerrariaPaid/config.json` 并确认来源。本版限主用户、主存储、shell UID 2000、Shizuku API 13+。
4. 英文配置点击“切换中文”，确认游戏完全退出。工具箱依次备份、核验、写回并回读；完成后再启动游戏确认中文。已为中文时无需修改。
5. “其他授权方式”保留 SAF 目录/文件入口。同名普通文档无法证明是游戏原配置时，仅可读和备份；可以主动“导入为副本”。

“已授权”“可尝试写入”“写回回读通过”和“游戏中文显示”含义不同。手机重启后先重新启动 Shizuku，再打开工具箱检查连接。授权失效时重新连接，或使用导入副本模式。

## MT 复制与导入副本

1. 用能够访问原目录的 MT 将原 `config.json` 复制到可访问位置。确认复制的是当前游戏使用的配置。
2. 进入“导入副本”，点击导入并选择副本；文件可用任意名称，只要求读取权限。严格校验通过后保存在应用内部，导入源文件始终不会修改。
3. 仅保留一个当前编辑副本。再次导入有效配置时需确认替换，工具箱先备份旧副本；取消、无效 JSON 或保存失败保留旧副本。历史备份不自动删除。
4. 英文副本点击“生成中文并导出”，先保存并核验原始字节备份，再仅修改根对象 `Language: 1 → 7`。中文副本原样导出，不重复生成或自动备份。
5. 在系统保存页面选择**新的文件**，默认名称为 `config.json`。工具箱关闭写入后回读核对哈希，展示实际名称和 URI；禁止覆盖导入源、已知游戏原文件及可识别别名。
6. 取消导出会保留已经生成的中文副本和原始备份，之后可再次导出。导出失败或无法回读时结果未确认，换位置重试。
7. 完全退出游戏，用 MT 将已导出的文件替换原配置，最终名称必须为 `config.json`。`export.json` 或 `config (1).json` 必须正确改名。启动游戏确认中文显示。

导入、生成、导出和副本恢复无需启动 Shizuku。导出成功仍未替换游戏原文件，工具箱不会自动执行 MT 操作，也不会自动关闭游戏。

## 备份与恢复

从工具页进入“备份历史”。备份区分“外部配置”和“编辑副本”，逐字节保存原内容。卸载或清除数据会丢失内部备份，建议导出重要原始备份。

- 外部配置只能完整恢复到同来源、同后端的游戏目标。先完全退出游戏；工具箱备份当前字节，再恢复选中备份并回读核验。**完整恢复同时还原音量、按键等全部设置。**
- 编辑副本备份只恢复到同一工作副本；恢复前备份当前副本。替换为新副本后旧副本备份只能导出，不自动恢复到新副本或游戏目标。
- 手动恢复：导出对应原始备份，完全退出游戏，用 MT 以 `config.json` 名称替换原文件。只在编辑副本中恢复不会还原已被 MT 替换的游戏文件。

## 未完成写入与诊断

首页和工具页面出现“需要检查或恢复”时，**暂勿启动游戏**。连接原来源后重新校验上次结果，不一致时通过备份历史完整恢复或导出原始备份。返回首页或切换到副本模式不会清除未完成记录；新的直接切换被禁止。

进入“诊断与记录”，填写游戏与 MT 版本，可经系统保存入口导出本机记录。记录不包含配置内容或配置里的用户标识。1.1 已有用户实测正常反馈；请按本版真机模板补录设备、版本、重启与 MT 流程结果。其他设备需独立验证。
