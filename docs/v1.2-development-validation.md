# 1.2 完整第一版开发验证

日期：2026-10-11（Asia/Shanghai）。版本 `1.2 / 3`，包名 `com.example.terrariatoolbox`，`minSdk 34`、`compileSdk/targetSdk 37`，Shizuku 客户端依赖保持 `13.1.5`。

## 功能与存储

绿色 Material 3 首页仅提供中文切换。工具页分直接切换、导入副本两种模式，备份历史、使用说明及诊断记录为次级页面。ViewModel 归属单 Activity，返回首页不取消 IO 操作；首页和各页面均保留外部未完成操作警告。

副本保存在 `noBackupFilesDir/copy-workspace`，原始备份及旧会话仍在 `noBackupFilesDir/validation`。先落盘不可变内容、核验字节哈希，再原子提交 `current.json` 引用。有效替换需确认并备份旧副本，取消或失败不替换；未提交内容不参与当前副本加载，不自动删除历史备份。`workspaceId` 缺失仍是外部来源记录。

## 实际覆盖安装

在专用 API 34 安装原交付的 1.1 APK，通过真实 Shizuku UI 读取 2 MiB 英文夹具、确认来源并保存原始备份。随后注入一份 1.1 格式的未完成操作记录，结束进程，使用 `adb install -r` 覆盖安装 1.2，未卸载或清除数据。

升级前后 `source.json`、`pending.json`、该备份 `.bin/.json` 共四个文件 SHA-256 完全相同。新版读取旧 `SHIZUKU` 来源、无 `workspaceId` 的备份及 pending，首页显示恢复提示，禁止新的直接切换；旧备份可导出且导出内容与原字节一致。原 1.0 SAF 升级证据保留于 Shizuku 阶段，JVM 继续覆盖字段缺失按 SAF、外部备份读取。

未完成记录和进程恢复使用受控状态注入，并非对真实游戏文件做断电测试。测试后将注入的 journal 标记为完成，以隔离普通回归。Gradle 普通仪器测试会卸载目标和测试 APK，这项清理与覆盖升级验收分开。
