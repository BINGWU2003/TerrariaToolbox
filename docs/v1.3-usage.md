# 1.3 使用说明

工具箱可以把泰拉瑞亚的游戏语言切换为中文或英文。切换只影响语言，音量和按键等设置会保持原样。

## 第一次使用

1. 先打开一次泰拉瑞亚，再完全退出游戏。
2. 打开工具箱，在首页安装并打开 Shizuku。
3. 按 Shizuku 的提示，通过「无线调试」完成配对并启动。不熟悉操作时，可以点首页的「查看详细安装与启动教程」。
4. 回到工具箱，点击「连接 Shizuku」，在授权弹窗中选择允许。
5. 看到当前游戏语言后，点击首页的「游戏语言」进入工具。

手机重启后，需要重新启动 Shizuku，再回到工具箱连接。

## 切换中文或英文

1. 完全退出泰拉瑞亚。
2. 在「游戏语言」中点击「切换到中文」或「切换到英文」。当前正在使用的语言无需再次切换。
3. 确认已经退出游戏。工具箱会自动备份原来的设置，再保存新语言。
4. 看到「已切换为中文」或「已切换为英文」后，重新打开游戏。

工具箱只识别中文和英文的游戏设置。无法读取或遇到其他语言时，会停止修改并显示提示。

## 备份与恢复

每次切换语言都会自动备份，无需先手动保存。也可以在「更多操作」里点击「备份当前设置」。

「更多操作 → 恢复备份」可以查看和导出备份。**恢复备份会还原备份时的全部设置，包括语言、音量和按键。** 如果只是想从中文切回英文，直接使用「切换到英文」即可。

恢复前需要完全退出游戏，并再次确认。工具箱还会先备份当前设置，方便之后找回。

备份保存在本机；卸载工具箱或清除数据会删除它们，长期保留时请先导出。

## 遇到问题

- 没有找到游戏设置：先打开一次游戏，再完全退出，然后重新连接。
- Shizuku 断开：打开 Shizuku 确认已启动，回到首页重新连接。
- 提示「上次操作需要检查」：先不要打开游戏。重新连接后点「检查上次操作」；检查未通过时恢复备份。
- 仍无法完成：进入「更多操作 → 问题排查」，可以查看技术信息或导出问题记录。记录不包含游戏设置内容。

## 从旧版本升级

直接覆盖安装 1.3，保留原有备份和操作记录。新版只通过 Shizuku 修改游戏，不再提供选文件、目录授权和配置副本导入入口。

旧版本的文件或副本备份仍可导出保存，它们不会被恢复到当前 Shizuku 游戏设置。旧版留下的文件写入中断记录也会保留并显示提示，需要先导出对应备份，按原来的方式恢复游戏设置。
