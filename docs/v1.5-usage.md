# 1.5 使用说明

安装 `artifacts/v1.5/TerrariaToolbox-v1.5-debug.apk`，可覆盖安装旧版。底部固定「首页 / 存档 / 工具」，顶部「帮助」提供连接、使用说明与问题排查。

## 连接游戏

首页显示实际 Shizuku 状态。未安装时进入官方安装说明，未启动时打开 Shizuku；按无线调试步骤配对、启动，再回工具箱连接并允许授权。手机重启后需要重新启动 Shizuku。国服存档与国际服存档分别管理；语言工具仅支持国际服。

## 查看与导出存档

在「存档」中选择游戏版本。国服单账号自动选择，多账号需选择；工具箱记住上次版本与账号，但每次连接后重新核实账号是否存在。更换目标会清空旧目标的选择。

顶部「角色 / 世界」分类显示实际数量。搜索按文件名匹配，默认按修改时间从新到旧排序，可切换名称或大小排序。点击文件或「选择并导出」进入选择模式，可跨角色／世界选择；总选择数和导出按钮保持可见。全选仅作用于当前分类的搜索结果。返回其他页面后保留分类、搜索与选择。

单个存档导出原文件，多个导出按 Players/Worlds 分组的 ZIP。系统保存位置选下载等普通文件夹；保存后重新读取检查内容，成功后可查看文件。取消或失败保留选择，可再次导出；手机没有可打开此格式的应用时，仍可在保存的位置找到文件。

## 引导式导入

1. 从首页「导入存档」或存档页开始。选择手机 .plr、.wld、ZIP，或内置存档；这一阶段不要求 Shizuku 连接。
2. 工具箱在缓存中检查扩展名、大小、非空、ZIP 内容与路径。检查不保证游戏版本兼容，不转换存档格式。
3. 连接 Shizuku，选择目标国服／国际服及国服账号。去帮助修复连接后返回，已检查文件仍保留。
4. 检查目标与清单，完全退出游戏后点击「已退出游戏，开始导入」。同名自动编号，例如 `Vor (1).plr`，保留已有存档和原文件内容，游戏内名称可能仍相同。
5. 查看实际进度和逐项结果，可以「查看存档」或「继续导入」。部分文件检查失败时会明确说明跳过数量及原因。

确认前可以返回上一步或取消；正在写入时禁用重复操作与页面切换。离开向导后，存档页可继续已检查但尚未导入的文件。

## 游戏语言

「工具」显示实际读取的国际服当前语言。完全退出国际服后选择中文／英文，再明确确认。修改只影响语言，音量和按键保持原样；完成后重新打开游戏。

手动设置备份、备份历史、日常恢复入口已移除。切换前仍会在内部保存原字节用于写入异常恢复。只有未完成写入或异常操作记录存在时，才显示检查／恢复入口；正常切回英文直接使用「切换到英文」。旧备份数据不删除。

## 范围

保留 1.4 的限制：仅处理 .plr/.wld 主文件，不包含地图探索或 .bak；每文件 64 MB，每批 256 MB，最多 500 个存档。ZIP 存档位于根目录或 Players/Worlds；危险路径、空文件和损坏压缩内容会拒绝。

目标选择保存在内部非云备份目录。存档选择、暂存导入与最近存档操作结果在当前应用会话中保留；进程被终止后需重新选择文件。写入时被强杀仍可能留下未确认的新文件，重新连接、刷新并检查后再试。语言写入继续沿用内部事务与恢复记录。
