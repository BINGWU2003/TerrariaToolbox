# 使用说明

适用于公开版 1.0.0。最低 Android 14，使用 Shizuku 访问游戏目录。

## 第一次使用

1. 从 [GitHub Releases](https://github.com/BINGWU2003/TerrariaToolbox/releases) 下载并安装 `TerrariaToolbox-v1.0.0.apk`。
2. 打开一次你要管理的游戏。国服需要登录账号，然后完全退出游戏。
3. 安装并打开 Shizuku，按照 [官方教程](https://shizuku.rikka.app/zh-hans/guide/setup/) 通过无线调试配对并启动。
4. 回到工具箱首页，点击「连接 Shizuku」，允许授权。

手机重启后需重新启动 Shizuku，再回工具箱连接。仅支持手机主用户、Shizuku API 13+ 与无线调试 shell 服务。文件选择器用于手机文件导入和导出保存，不需要用它授权游戏目录。

底部导航为「首页／存档／工具」。首页提供连接状态、导入／导出快捷入口、游戏语言和最近操作，页面底部可打开 GitHub 项目或作者哔哩哔哩主页。顶部「帮助」包含连接步骤、使用说明与问题排查。

## 查看与导出存档

在「存档」中选择国际服或国服。国服单账号自动选择，多账号需要选择；工具箱记住上次目标，但连接后会重新核实账号。更换目标会清空旧目标的选择。

顶部「角色／世界」分类显示实际数量。可以搜索文件名，按修改时间、名称或大小排序。点击存档或「选择并导出」进入选择模式，可跨角色与世界多选；全选只作用于当前分类的搜索结果。切换页面后保留分类、搜索与选择。

单选导出原 `.plr`／`.wld` 文件，多选导出 ZIP。通过系统文件选择器保存到下载等普通文件夹，保存后工具箱回读检查。取消或失败会保留选择，可以再次导出。

ZIP 中的 `terraria-toolbox.json` 记录所属服、各主文件路径、大小与 SHA-256，不记录账号 ID。导出后应完整保留清单和存档内容，改动清单或文件可能导致重新导入被拒绝。

## 导入存档

1. 从首页「导入存档」或存档页开始，选择手机 `.plr`、`.wld`、ZIP，或「浏览内置存档」。选文件阶段无需连接 Shizuku。
2. 工具箱在缓存中检查扩展名、大小、非空、ZIP 路径和内容。检查通过不代表任意游戏版本都能加载文件。
3. 确认来源服，连接 Shizuku 并核实同服目标；国服需要核实账号。
4. 核对目标和文件清单，完全退出游戏，点击「已退出游戏，开始导入」。
5. 查看进度与逐项结果，完成后可查看存档或继续导入。

同名会自动编号，例如 `Vor (1).plr`，保留已有文件及存档原内容。游戏内名称可能仍相同。确认前可返回上一步或取消；写入期间会禁用重复操作和页面切换。

手机世界文件的已知 `relogic`／`xindong` 标记用于识别国际服／国服；角色、未知标记的世界及旧 ZIP，需要按原游戏或下载说明明确声明所属服。声明不能覆盖已识别来源。同一批文件只能属于一个服；两服混合、来源与标记冲突或 ZIP 清单校验不一致时，整批停止，应重新按服选择。

来源信息用于减少误选，不是签名认证。工具箱不转换、不解密或更改存档内容；同服也需要目标游戏支持相应存档版本。

## 内置存档

先选择所属服，再按角色／世界浏览。同服可以跨分类多选；切换所属服会清空选择。选好的资源绑定同服目标，不能改为另一服导入。

| 所属服 | 角色 | 世界 |
| --- | --- | --- |
| 国际服 | Galactus、Molt、Starduster、Vor | 1_4_4+ALL_ITEMS MAP_-_By_Scopey(3)、（经典）言寺全物品1.4.5.8 |
| 国服 | 暂无内置角色 | （经典）心动国服 言寺全物品1.4.5.8 |

「暂无国服内置角色」仅表示工具箱未附带资源，已有国服角色仍可查看、导出，也可从手机导入同服角色。文件名中的版本号属于资源名称，不证明其他游戏版本可以加载。

## 游戏语言

「工具」显示读取到的国际服当前语言。完全退出国际服，选择中文或英文，再确认已退出游戏。看到完成提示后重新打开游戏。切换只修改语言，音量与按键保持原样；国服不使用此工具。

工具箱只处理中文／英文设置，遇到其他语言或无法读取时会停止修改。日常切回英文直接选择「切换到英文」。

每次语言写入前会在应用内部保存原字节，用于异常恢复。出现「上次设置操作需要检查」时，先不要打开游戏，重新连接并检查；检查未通过时使用恢复入口。恢复会还原该次操作前的语言、音量和按键等完整设置。内部备份不会随系统云备份上传，卸载或清除数据会删除它们。

## 问题排查与限制

- Shizuku 未启动或断开：打开 Shizuku 确认已启动，再回首页重新连接并允许授权。
- 没有国际服设置：先打开一次国际服，完全退出后重新读取；没有国际服设置也可管理已连接的存档。
- 国服没有账号：登录游戏后完全退出，再重新连接或刷新；账号以实际数字目录为准。
- 操作仍失败：进入「帮助 → 问题排查」导出问题记录，记录不包含游戏设置内容。
- 正在导入时进程被终止：重新连接、刷新并核对已有存档后再试，可能已有新文件写入。

只导入／导出主存档，不包含 `.bak` 或地图探索附属文件。单文件 64 MB、每批 256 MB、最多 500 个存档。ZIP 仅接受支持的存档路径；危险路径、空文件和损坏内容会拒绝。

分类、选择与暂存导入在当前会话中保留；进程退出后需重新选文件。目标服与国服账号保存在内部，并在连接后重新核实。

公开版与旧测试版使用不同包名及签名，分别安装，内部数据不迁移。旧测试版如存在未完成写入，请先在旧版处理恢复；以后公开版可用相同签名覆盖更新。
